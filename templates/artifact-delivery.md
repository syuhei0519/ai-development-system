# JSON 配送を明示的に使う場合

通常の学習記録は [Markdown Handoff](handoff.md) を使う。
配送 JSON が必要な場合だけ、4記録の schema_version をすべて 1.3 とする。
Handoff 2.0 / Knowledge 1.0 / Readiness 1.1 など、内容側の契約版は変更しない。

- 対象 repo と固定 commit、目的・利用範囲
- 原本の実体と artifact / slot / Knowledge / candidate の参照
- 承認元と期限、公開可否、利用可否
- 実行した検査、観察結果、未確認点

旧版の記録を現行版へ書き換えて利用せず、当時の固定 Git 履歴で再現する。
詳細は [現行契約](../contracts/README.md) を参照する。
